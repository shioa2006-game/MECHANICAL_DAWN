# MECHANICAL DAWN — 機械都市の夜明け

10歩ぶんの電力で目覚めた小さな探索ロボ〈ホタル〉が、**自分の足跡を送電網として残しながら**、止まった機械都市を再生させるブラウザゲームです。
初回クリアまでの想定プレイ時間は 15〜25 分程度です。

---

## 1. 起動方法

ビルドもインストールも不要です。外部のゲームエンジン、画像ファイル、音声ファイルは使っていません（グラフィックと音はすべてコードで生成しています）。

**方法A（いちばん簡単）**
`index.html` を Chrome / Edge / Firefox で直接開く（ダブルクリック）。

**方法B（ローカルサーバー）**
```bash
python tools/serve.py
```
ブラウザで `http://127.0.0.1:8765/` を開く。Node があれば `npx serve` など任意の静的サーバーでも動きます。

- 表示フォント（DotGothic16）は Google Fonts から読み込みます。オフラインのときは代替フォントで表示されます。
- 進行状況はブラウザに自動保存されます（localStorage）。タイトル画面の「つづきから」で再開できます。
- 推奨環境：PC ブラウザ＋キーボード＋マウス（音が出ます）。スマートフォンでもタップで遊べます。

## 2. 操作方法

| 操作 | 内容 |
|---|---|
| **WASD / 矢印キー** | ホタルを1歩ずつ動かす |
| **マウスを地面に乗せる** | 経路と消費バッテリーをプレビュー（「バッテリーが2足りない」、漏電床で回収されうる歩には ⚡ を表示） |
| **地面をクリック** | その場所へ移動（届くところまで進む） |
| **R** / 帰還ボタン | 基地へ帰還して満充電（仮設ケーブルも確定する） |
| **B** / 中継塔ボタン | 中継塔の配置モード。電気の届いているケーブルをクリックすると建つ（新しく電気が届くマスを水色で表示。右クリック・Esc でやめる） |
| **施設・資源・ロボットをクリック** | 詳細カード（復旧の開始／「ホタルで向かう」／役割の変更） |
| **右パネル［ロボット］の ＋ / −** | ＋：待機ロボを割り当て、いなければ製造。−：待機に戻す |
| **右パネル［ホタル強化］** | 強化の購入 |
| ドラッグ / ホイール・Q・E / Space | 視点移動 / ズーム / ホタルを中央へ |
| F または「×1」ボタン | ゲーム速度 ×1 / ×2 / ×3（ロボットの作業を早送り） |
| M / H / Esc | 音のオンオフ / 遊び方 / メニュー |
| タッチ操作 | タップでプレビュー → 同じ場所をもう一度タップで移動、ドラッグで視点、ピンチでズーム |

### クリア条件
1. 3つの**変電所**を復旧する
2. **中央動力炉**に送電網をつなぎ、資源と修理ロボの作業で復旧する
3. 最後に**ホタルを動力炉の隣まで動かして点火**する → 夜明け（エンディング）

画面左上の「次の目標」と、その下のヒント（クリックできるものあり）が常に次にやれることを示します。

## 3. 採用した主要なゲームデザイン

### 中心ルール：足跡が送電網になる
- 新しい地面に1歩進むと**バッテリーを1消費**し、そのマスに**送電ケーブル**が残る。
- ケーブル（送電網）の上は**バッテリー0で高速移動**できる。
- バッテリーが尽きると自動で基地へ帰還して満充電。出撃は何度でもできるが、**送電網の端から10歩**が一度に届く限界になる。
- つまり1回の出撃は「送電網をどこへ10マス伸ばすか」という判断になる。

### 追加ルール1：仮設ケーブルと漏電床（無事に帰るまで、今回の道は確定しない）
- その出撃で敷いたケーブルは**仮設**（点線で表示、まだ電気は流れない）。**基地に帰る**か、**施設・資源・古い送電線につなぐ**と確定する。
- 闇の中の道路には**漏電床**が隠れている。踏むとバッテリー **−3**。足りなければ**過放電で緊急回収**され、その出撃の仮設ケーブルと拾った物（元の場所に戻る）を失う。さらにサージが送電網を逆流し、**一番近い発電機か変電所が損傷**する（修理ロボが直すまで発電が止まり、壊れた設備は火花を散らす）。送電網全体も3秒だけ停電する。見つけた漏電床と地形の情報は残る。
- 漏電床の周囲8マスには**火花の粒**が見え、粒の数＝周囲の漏電床の数（マインスイーパーと同じ読み方）。広域スキャナがあれば視界内の漏電床そのものが見える。一度ケーブルを敷いた漏電床は無害になる。
- 経路プレビューは「この歩で漏電床なら回収される」マスに ⚡ を付ける。残りバッテリーが少ないときに「もう1歩踏み込むか、帰って確定させるか」を毎回選ぶことになる。

### 追加ルール2：電圧（電気が届く距離）と中継塔
- 電気は電源から**ケーブル沿いに一定のマス数しか届かない**：基地16マス、復旧した変電所14マス。**古い送電線は損失なし**で電気を運ぶ。
- 届かない先のケーブルは光らず、ロボットは入れず、施設や資源もつながらない。ケーブルの明るさが残りの電圧を表し、マウスを乗せると「電圧 N」「電圧不足」と表示する。
- 対処は3通り：**中継塔**（電気の届いているケーブルの上に置き、そこから12マス。費用はスクラップ8から1基ごとに+4、置いている間ずっと電力⚡1を使う）、**近道のケーブルを敷き直す**、**古い送電線・変電所を経由する**。
- 中継塔は電力を使い続けるので、古い送電線を直して中継塔なしで届かせるほど電力が浮く。遠回りの探索路はそのまま損になる。

### 追加ルール3：電力経済（⚡は「貯める量」ではなく「同時に動かせる量」）
- **発電**：基地 ⚡3、小型発電機（地図に4か所）各 ⚡3、変電所 各 ⚡6。結晶で買う「発電効率 I / II」で、稼働中の発電所すべてが +1 ずつ増える。最終的に ⚡40 前後。
- **使用**：採掘・運搬ロボ ⚡1、修理ロボ ⚡2、中継塔 ⚡1、コンベヤー ⚡2。待機中のロボは 0。**ホタルの充電は電力を使わない**（電力待ちで探索が止まらないように）。
- **足りないとき**：使用が発電を超えると、都市全体の作業（ロボの移動・採掘・修理・製造・コンベヤー）が遅くなる。速さは「発電 ÷ 使用」の**2乗**（75%なら56%）なので、発電を超えてロボを作るのは損になる。止まりはしないので、詰むことはない。
- **貯めるものがない**ので、「貯まるまで待つ」「止めて貯めて動かす」という操作は得にならない。プレイヤーが決めるのは、ロボの役割と台数、どの発電所を取りに行くか、中継塔か古い送電線か、という方針だけ。
- **ロボ枠は廃止**。発電所を探して復旧するほどロボットを増やせ、最後は30体近くが働く。
- **電力不足は目と耳で分かる**：HUD の ⚡ は「使用/発電」と使用率のバーで表示し、不足すると枠ごと赤く点滅して「電力不足 作業N%」と出る。不足になった瞬間に警告音と通知が出て、マップ上では働くロボの頭上に ⚡ マークが点滅し、ケーブルと街灯がちらつく。マウスを乗せると消費の内訳と発電所の一覧が見える。
- ロボットパネルの＋は、押すと電力不足になる場合はオレンジ色になり、「作業速度 N%」と結果を事前に表示する。

### 送電網の意味（経路が残ることの戦略性）
| 送電網があると… | 内容 |
|---|---|
| 次の出撃の起点になる | ケーブルの先から続きを伸ばせる |
| ロボットの道になる | NPCロボットは**送電網の上しか動けない**。網の形がそのまま物流網になり、運搬距離＝生産効率になる |
| 施設・資源がつながる | 施設や鉱床に**隣接**すると接続。接続したものだけが復旧・採掘できる |
| 古い送電線が復活する | 街に眠る古い送電線に触れると、**断線（火花）までの区間が一気に通電**して街灯が順に灯る。断線は修理ロボだけが直せる |

### 地形と強化（強化すると地図の見え方が変わる）
| 強化 | 効果 |
|---|---|
| バッテリー増設 I / II / III | 1回の出撃で進める距離 +3 / +3 / +4 |
| ドリルアーム | 瓦礫を砕いて進める（1マス2消費）。砕いた跡はロボットも通れる近道になる |
| ホバー脚 | 冷却水路の上を進める。敷いたケーブルが**橋**になり、ロボットも渡れる |
| 広域スキャナ | 視界拡大。地中に埋まった古い送電線、霧の中の資源、視界内の漏電床が見える |
| 発電効率 I / II（結晶） | 稼働中の発電所すべての発電 +1 / さらに +1 |

そのほか、地面の**予備電池**（最大バッテリー+1）、**休眠ロボット**（触れると仲間になる）、**記録データ**（街の物語）が探索の寄り道の報酬です。

### 資源・ロボット・施設
- 資源の役割：**電力 ⚡**＝今なにを動かすか／**スクラップ ⚙**＝何を建てるか（ロボ・施設・発電機・中継塔・強化）／**結晶 ◆**＝どう伸ばすか（発電効率・高度な装備・変電所・中央動力炉）。
- ロボットの役割は4つ：**スクラップ採掘／結晶採掘／運搬／修理**。役割の変更は無料でいつでもできる。
  - 採掘ロボは鉱床の横の置き場（最大12）に積むだけ。**運搬ロボが基地か倉庫へ運んで初めて使える**。
  - 鉱床は尽きないが、1か所に採掘ロボは2体まで。もっと掘るには新しい鉱床を探して接続する。
  - 修理ロボは施設の復旧作業、断線、壊れた街灯を直す。
- ロボットの台数に上限はない。何体動かせるかは発電量で決まる（上の「電力経済」）。

| 施設 | 復旧すると |
|---|---|
| ロボット工場 | ロボット製造が可能に、休眠ロボ1体が目覚める |
| 小型発電機 ×4 | 発電 ⚡+3（スクラップ12、修理作業なし）。西は基地のすぐ近く、東は漏電床の多い工業区、北西は運河の向こう、北東は中枢区の外れ |
| 電波塔 | 周囲14マスの地図と全施設の位置が判明 |
| 集積倉庫 | 運搬ロボの荷下ろし先になる（運搬距離が短くなる） |
| コンベヤー | 結晶鉱脈から倉庫へ自動搬送（倉庫が必要） |
| 第1〜第3変電所 | 発電 ⚡+6、出撃バッテリー+2、**14マス送電する電源**になる、その街区の窓に明かりが灯る |
| 中央動力炉 | 点火すると夜明け（クリア） |

### マップ
手作りの 48×32 マスの都市。基地のある南西区から、瓦礫の向こうの工業区（ドリル）、運河の向こうの北西区（ホバー）、冷却水路に囲まれた中枢区の中央動力炉へ。ドリル先行・ホバー先行どちらのルートでも進められます。

### 演出
- 世界は夜。ホタルのランプ、ケーブル、街灯、復旧した施設、窓の明かりだけが闇を照らす。
- **都市復旧率**が上がるほど空が夜→紫の夜明け前へ変化し、音楽にパッド・リズム・アルペジオ・メロディの層が加わる。
- 施設の復旧は「明滅しながら点灯 → 光のリング → 画面の揺れ → バナー → カメラが寄る → ファンファーレ」。
- エンディングでは中央炉の光の波が街に広がり、朝焼けの中を眠っていたロボットたちが行き交う。

## 4. 3つの面白さの仮説をどう実現したか

### 仮説A「あと10歩だけ探索したい」
- 経路プレビューが「**バッテリーが2足りない**」と具体的に示す → 次の出撃なら届く、と分かる。
- 出撃の成果（ケーブル）はすべて残り、次回はケーブル上を0消費で先端まで走れる。毎回が前回の続き。
- 闇の中で点滅する施設の信号、光るスクラップ、遠くに見える中央炉の影、触れると一気に通電する古い送電線、という「行ってみたくなる理由」を常に視界に置いた。
- 強化のたびに、瓦礫が近道に、水路が橋に、地中の送電線が見えるようになり、既知のマップに新しい選択肢が生まれる。
- 帰還時に「送電路 +10 ／ ⚙+6 ／ 発見：○○」と成果をまとめて表示。

### 仮説B「あと1体ロボットを増やしたい」
- 採掘と運搬を分けたので、**運搬不足は鉱床横に積み上がる木箱と「滞留 N」として目に見える**。満杯で採掘ロボが止まると「!」が出る。
- 役割は＋/−で即座に組み替えられる。復旧中は修理に寄せる、結晶が要る時は結晶採掘に寄せる、といった判断が生産量（HUDの「+N/分」）に直結する。
- 採掘枠（1か所2体）と運搬距離（送電網の形）があるので、「ロボットを足す」「新しい鉱床を探す」「近道を通す」「倉庫を直す」のどれが効くかを比べることになる。
- 何体動かせるかは発電量で決まる。「あと1体」の欲求が「あと1つ発電所を」へつながる。

### 仮説C「あと1施設復旧させたい」
- どの施設も新しいこと（製造／広域地図／物流短縮／自動搬送／発電＋バッテリー）を可能にするので、次の施設が欲しくなる。発電所を復旧すると、遅くなっていた都市全体が一斉に動き出す。
- 復旧の瞬間を演出で強調し、街区の窓が一つずつ灯り、街灯が連鎖して点き、音楽の層が増えていく。
- 復旧率は空の色・明るさ・音楽に反映され、数字だけでなく見た目と音で「街が戻ってきた」と分かる。

### 3つの循環
探索（ケーブルを伸ばす）→ 接続（資源・施設・発電所・古い送電線）→ ロボットが網の上で働く → 資源で強化と復旧 → 発電所で動かせるロボが増える → さらに遠くへ。
探索だけはホタルにしかできず、ロボットが増えても「どこへ網を伸ばすか」はプレイヤーの仕事として残ります。

## 5. 実施したテストと結果

```bash
node tests/run-tests.js     # ルールの単体テスト + ボットによる通しプレイ
node tests/fuzz.js 40       # ランダムな戦略でクリアできるか（引数は試行回数）
node tests/bot.js -v        # ボットの通しプレイを詳細ログ付きで実行
node tests/measure.js 5     # 方針の違うボットで時間配分・電力収支・発展経路を計測
```

- **ルールテスト 42件：すべて成功**（電力の発電・使用・作業速度・停電・発電機・発電効率・サージによる損傷と修理、歩数とバッテリー、仮設ケーブルの確定、ケーブル上の0消費、自動帰還と充電、漏電床の消費・既知化・緊急回収・スキャナ、漏電床の配置条件、電圧の到達距離・中継塔・古い送電線の無損失・変電所の電源化、古い送電線の連鎖と断線、施設の接続と復旧、採掘と運搬、修理、役割変更、強化、動力炉の条件、点火、セーブ／ロード、「ホタルで向かう」、基地をまたぐロボットの経路）。
- **ボットによる通しプレイ**：UI と同じ API だけを使う自動プレイヤーが最初からエンディングまで到達（ゲーム内時間 7分45秒、ロボット28体）。ボットは発電量の範囲でロボを増やし、中継塔を建て、スクラップが足りないときは近道を敷き直し、慎重型は ⚡ の歩を避けて帰還する。
- **ランダム戦略の通しプレイ**：探索順・強化順・復旧順・ロボット構成・漏電床の配置・慎重型／無謀型をランダム化した40通りで詰みが起きないか確認（結果は下記「テスト結果の記録」）。
- **ブラウザでの確認**（内蔵ブラウザで実際に操作）：タイトル → イントロ → キーボード／クリック移動 → 経路プレビュー → 自動帰還 → 工場の接続と再起動 → ロボットの割り当てと製造 → 強化購入 → 中盤（工業区・倉庫・コンベヤー）→ 中央動力炉の点火 → エンディング画面、遊び方画面、スマートフォン幅の表示。コンソールエラーなし。

テストで見つかり修正した主な不具合：
- 基地の別々の側から伸ばしたケーブル同士をロボットが行き来できず、鉱床が永久に放置される（ランダム戦略テストで発見）
- 近くの鉱床が常に優先され、遠くの結晶鉱脈を運搬ロボが一度も回収しない（優先度に待ち時間を加味して解消）
- 速いキー入力が上書きされて歩数がずれる／キー長押しで余計に歩いてバッテリーを無駄にする
- 未探索の先をクリックすると、見えた壁で止まってしまう（自動で迂回するよう改善）
- 施設の一部しか見えず闇に埋もれる、記録データの表示が他の通知と重なる、など

**人間による実プレイはまだ行っていません。** ボットはマップを知っているため、人間のクリア時間はボットの2〜3倍（15〜25分程度）と見積もっていますが、未検証です。

## 6. 現時点で残っている課題

- **人間による難易度・テンポの検証が未実施**。特に、探索を終えた後に資源待ちになる時間（ボットでは最後の数分）が退屈に感じられないかは実プレイで確認が必要。待ち時間対策として速度切替（×2/×3）を用意している。
- **ボットはまだ基地で待つ時間が長い**（全体の約7割）。地図を知っているボットは探索をクリアの6〜9割の時点で終え、残りは復旧作業と中央動力炉の資源を待っている。人間は探索により長くかかるはずだが、終盤の待ちが残るかは実プレイで確認が必要。
- **方針による発展経路の違いはまだ小さい**。クリア時間と電力不足の時間には差が出たが、発電所を復旧する順番はどの方針でもほぼ同じ（地図上の到達順で決まってしまう）。探索優先が常に最速で、ほかの方針に固有の得がまだ弱い。第2段階（地域ごとの鉱床の特徴）で差を作る余地がある。
- **漏電床の罰**：実プレイで「停電10秒は痛くない」との感想を受けて、近くの発電所が壊れる形に変えた。1回あたりの損は大きくなったが、ボットでは過放電そのものが1ゲーム1回未満と少なく、クリア時間の差はまだ小さい。人が遊んで痛いと感じるか、再確認が必要。
- **電力不足の見え方**：実プレイで「よく分からない」との感想を受けて、HUD・マップ・音・通知で示すようにした。分かるようになったか、再確認が必要。
- 電力の数値（発電・使用量）、漏電床の密度、電圧の値（基地16・変電所14・中継塔12）は、ボットで詰みが出ず、資源の偏りが消える範囲に合わせただけで、面白さの観点ではまだ調整していない。
- 火花の粒（周囲の漏電床の数）は人間が数えて推理できるかを未確認。読みづらければ数字表示に切り替える余地がある。
- 音はすべて WebAudio でその場で合成している。自動テスト環境では実際に聴けていないため、音量バランスは実機で調整の余地がある。
- マップは1種類の手作り。2周目以降の変化はない。
- スマートフォンは「遊べる」レベルの対応。画面が狭いとパネルと地図の切り替えが多くなる。
- ロボット同士の渋滞や衝突は表現していない（同じマスに重なれる）。
- 送電網のマスを取り除く（引き直す）機能はない。遠回りのケーブルは近道を追加して改善する設計（電圧は最短の経路で決まるので、近道を足せば遠回りの損は消える）。
- セーブデータの形式を変えたため、改修前のセーブは「つづきから」に出ない（はじめからになる）。
